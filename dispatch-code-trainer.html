Why this code?

Reading a code: 06D2

06 = protocol (Breathing Problems) · D = priority level (Delta) · 2 = specific determinant within that protocol.

Codes are written 06D2 or 06D02 and spoken "Six-Delta-Two."

Priority levels

  • Echo — immediately life-threatening (arrest, agonal breathing). Closest units of any type, max response.
  • Delta — unstable or high risk of deterioration. Typically ALS, lights & sirens.
  • Charlie — potentially serious but currently stable. Usually ALS.
  • Bravo — moderate acuity or unknown status. BLS-appropriate in many systems.
  • Alpha — low acuity. Routine (cold) response.
  • Omega — may be handled by referral or alternate response rather than an ambulance.

The code ≠ the response

The determinant describes medical priority. Each agency's response plan decides what actually rolls:

AlphaAgency A: BLS cold · Agency B: BLS cold
BravoA: BLS + ALS intercept · B: ALS hot
CharlieA: ALS hot · B: ALS cold
DeltaA: ALS + fire · B: ALS + fire + supervisor
EchoMultiple units, closest resources

How real calltakers do it

Live calls start with Case Entry (address, callback, "tell me exactly what happened," age, conscious?, breathing?) which picks the protocol — then scripted Key Questions drive the determinant. Most centers run ProQA software that presents one question at a time; the dispatcher never reads the determinant list. That's what Guided mode simulates.

Selection rule

The system selects the single highest determinant that applies. In Checklist mode, check multiple findings and watch the code jump — that's how a chest-pain call upgrades from Charlie to Delta when the caller adds "he's pale and sweaty."
